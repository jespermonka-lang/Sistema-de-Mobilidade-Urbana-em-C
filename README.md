# Sistema de Planejamento de Mobilidade Urbana

## Sobre o projeto

O projeto consiste no desenvolvimento de um sistema computacional em linguagem C para auxiliar no planejamento da mobilidade e da infraestrutura urbana, utilizando grafos ponderados para representar bairros, ruas e suas respectivas distâncias.

## Funcionalidades

- Carregamento de dados a partir de arquivos de texto.
- Representação da cidade por matriz de adjacência.
- Análise de conectividade entre bairros.
- Identificação de regiões isoladas utilizando Busca em Profundidade (DFS).
- Cálculo de rotas de menor custo utilizando o algoritmo de Dijkstra.
- Planejamento de uma rede cicloviária de menor custo utilizando o algoritmo de Prim.
- Menu interativo para utilização do sistema.

## Conceitos abordados

- Algoritmos e estruturas de dados.
- Teoria dos grafos.
- Matrizes de adjacência.
- Recursividade.
- Manipulação de arquivos.
- Programação modular.
- Resolução de problemas computacionais.
